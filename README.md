# Computational Geometry Assignment

This project implements fundamental computational geometry algorithms and data structures in Python.

## Project Overview

This assignment covers key algorithms and techniques in computational geometry, including:
- **Convex Hull computation** in 2D and 3D
- **K-D Trees** for spatial searching and organization
- **Delaunay Triangulation**
- **Linear Programming** optimization
- **Helper utilities** for geometric operations and visualization

## Files and Modules

### Core Algorithms

- **`convex_hull.py`** - Implements Graham's Scan algorithm for computing 2D convex hulls
- **`convex_hull_3D.py`** - Extends convex hull computation to 3D point sets
- **`delaunay.py`** - Incremental Delaunay triangulation implementation
- **`kd_tree.py`** - K-D Tree data structure for efficient spatial queries and range searching
- **`linprog.py`** - Linear programming utilities for optimization problems

### Utilities

- **`helpers.py`** - Common helper functions for geometric computations, point representations, and visualization
